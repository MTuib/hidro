# Biblioteques distribuïdes

| Biblioteca | Versió | Origen | Llicència conservada |
| --- | --- | --- | --- |
| Chart.js | 4.5.1 | Paquet npm `chart.js@4.5.1`, distribució UMD minificada | `WEB site/labmanager/core/static/vendor/chartjs/LICENSE.md` |
| @kurkle/color | 0.3.4 | Dependència inclosa dins la distribució Chart.js | `WEB site/labmanager/core/static/vendor/chartjs/LICENSE-kurkle-color.txt` |

La biblioteca, el mapa de fonts i les llicències s'han copiat de la distribució publicada, sense modificar el codi de tercers. El web usa els fitxers locals de Django; npm no és una dependència d'execució del projecte.

Les dependències Python s'instal·len des dels manifests i no es redistribueixen dins aquest paquet.

Referències: [instal·lació Chart.js](https://www.chartjs.org/docs/latest/getting-started/installation.html), [integració UMD](https://www.chartjs.org/docs/latest/getting-started/integration.html).
